## 原始需求
> 帮我做一个向传统行业宣传稳定币收款项目的官网。所有东西都做好之后，我会提供服务器部署到生产环境，以便验收。

按《产品经理.md》的规则，信息不足时先提问，不自己假设。下面每个问题都给了建议默认值，您可以直接回"按默认"，也可以只改其中几条。

## A. 必须确认（会决定方案方向）
| # | 问题 | 建议默认 |
|---|---|---|
| A1 | 目标客户是哪些"传统行业"？（外贸出口、制造业、跨境电商、物流、旅游酒店、教育留学……） | 外贸出口 / 制造业 / 跨境 B2B 贸易 |
| A2 | 面向哪些国家或地区？网站用什么语言？ | 海外市场，中英双语，默认英文 |
| A3 | 网站的核心转化目标是什么？ | "预约演示 / 联系销售"表单 |
| A4 | 表单提交的线索送到哪里？（邮箱、存数据库、接 CRM） | 发到指定邮箱，同时在服务器本地留一份备份 |
| A5 | 品牌：用 Paypaz 的品牌、Logo、色系和域名吗？有现成素材吗？ | 用 Paypaz 品牌；没有素材的话 PM 起草，研发用占位 Logo |

## B. 内容与合规
| # | 问题 | 建议默认 |
|---|---|---|
| B1 | 产品卖点：支持哪些币种和链？能否换成法币结算？费率和到账时间可以公开吗？ | USDT/USDC，支持 TRON/Ethereum 等主流链，支持法币出金；不公开具体费率，写"联系我们获取报价" |
| B2 | 文案由谁提供？ | PM 起草，您审核后定稿 |
| B3 | 合规信息：有哪些牌照或持牌主体可以对外展示？ | 只写公司主体名称，不写牌照；页脚放风险提示、隐私政策和服务条款 |
| B4 | **风险提示**：如果面向中国大陆，宣传虚拟货币或稳定币业务有明确的监管风险，服务器还要做 ICP 备案。是否明确排除中国大陆市场？ | 排除中国大陆，只面向海外 |

## C. 范围（做什么 / 不做什么）
| # | 问题 | 建议默认 |
|---|---|---|
| C1 | 页面规模：单页落地页，还是多页官网？ | 多页：首页 / 解决方案（按行业分）/ 工作原理 / 安全与合规 / 关于我们 / 联系我们 |
| C2 | 是否需要内容管理后台（CMS）、博客、客户登录、在线真实收款演示？ | 都不做（首版明确不做） |
| C3 | 是否需要 SEO 基础优化和访问统计？ | 做 SEO 基础优化；统计先留接入位，不接具体平台 |

## D. 部署相关（运维提前关注）
| # | 问题 | 建议默认 |
|---|---|---|
| D1 | 服务器在哪个地区？操作系统是什么？ | 海外 Linux（Ubuntu 22.04/24.04） |
| D2 | 有没有域名？需要 HTTPS 吗？ | 有域名；用 Let's Encrypt 免费证书 |
| D3 | 期望的交付时间或优先级？ | 无硬性截止日期，以跑通流程为主 |
